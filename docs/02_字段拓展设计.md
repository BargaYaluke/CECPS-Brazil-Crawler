# 巴西招投标数据字段(特征)修改与拓展

> 基于参考样式 `brazil_procurement_report.xlsx`(766 行,23 列)的诊断与改造方案。
> 目标:支撑六大维度商机分析(数字经济 / 医疗医药 / 高端制造 / 大宗商贸 / 跨境电商 / 文化体育)。

---

## 一、当前样式的核心问题

| 问题 | 严重度 | 原因 | 修复方向 |
|---|---|---|---|
| `预估金额 Valor` 766 行**全部为空** |  致命 | search API 不返回 `valorTotalEstimado` | 切到 `/consulta/v1/contratacoes/publicacao` |
| **原生分类与六大维度不匹配** |  致命 | 当前 12 类分类(IT/医疗/工程…)≠ 业务六维 | 新增维度映射层 |
| `紧急度` 是**动态字段** |  中 | 存"7天内截止"标签,几天后失真 | 改存剩余天数(整数) |
| **没有项目明细 itens** |  致命 | 一个招标常含几十个采购项,各有 CATMAT 码 | 增加明细子表,作为维度分类依据 |
| 缺少**机构画像**与**区域画像** |  中 | 只有原始字段,没做富化 | 加 CNPJ / IBGE 富化字段 |
| 单 Excel 大宽表,**无法扩展** |  中 | 766 行还行,10 万行后崩溃 | 拆三张表:主表 / 明细 / 机构 |

## 二、字段拓展清单

按"必加 / 强烈推荐 / 加分项"三级分类。

### 2.1  必加字段(填补现有致命缺陷)

| 字段名 | 类型 | 来源 | 说明 |
|---|---|---|---|
| `valor_total_estimado` | float | API 直接返回 | 预估总金额(BRL) |

## 四、存储结构升级:从单表到三表

当前是一张 23 列大宽表,**10 万行后会非常难用**。建议拆成 3 张关联表。

### 4.1 主表 `contratacoes`(每个招标一行)

包含:基本信息、金额、时间、状态、六大维度标签、富化字段。
**约 35–40 列**,主键 `pncp_id`。

### 4.2 明细表 `itens`(每个采购项一行)

```
pncp_id (FK) | numero_item | descricao | quantidade | unidade
            | valor_unitario | valor_total | catmat_codigo | catmat_nome
```

一个招标 N 个项目,N:1 关联主表。**这是六大维度分类的最准依据**。

### 4.3 机构表 `orgaos`(每个采购单位一行)

```
cnpj (PK) | nome | esfera | uf | municipio
         | total_contratacoes_2y | total_valor_2y | last_active_date
         | tier (高/中/低活跃)
```

避免主表重复存机构信息,且方便做机构画像分析。

### 4.4 Excel 实现方式

- **Sheet 1**: 主表 `contratacoes`
- **Sheet 2**: 明细表 `itens`(用 VLOOKUP/XLOOKUP 关联)
- **Sheet 3**: 机构表 `orgaos`
- **Sheet 4**: 维度透视表(自动按维度/区域/金额段汇总)
- **Sheet 5**: 维度映射规则(可编辑的关键词词典,业务自维护)

数据量 >10 万行建议直接用 **SQLite** 或 **Parquet**,Excel 仅作展示层。

## 五、字段总览(最终目标:约 45 列主表 + 9 列明细 + 9 列机构)

### 主表 contratacoes(45 列)

```
[标识] pncp_id, serial_no, crawl_timestamp, last_updated_at, data_quality_score

[标题描述] title_pt, title_zh, title_summary_zh,
          description_pt, description_zh, description_summary_zh

[金额] valor_total_estimado, valor_total_homologado, valor_cny_estimado

[时间] data_publicacao, data_abertura, data_encerramento, dias_restantes

[分类-原生] raw_category, modalidade, tipo, esfera, situacao, cancelado

[分类-六维] dimension_primary, dimension_secondary, dimension_confidence,
          dimension_match_reason, keyword_match_score

[机构] orgao_nome, orgao_cnpj, unidade_orgao_cnpj,
      orgao_historico_contratos, orgao_total_valor_historico

[地理] municipio, uf, region_macro, region_gdp_tier

[规则] is_me_epp_exclusivo, permite_subcontratacao,
      requires_local_presence, modalidade_concorrencia_grau,
      tipo_recurso, idioma_edital

[明细聚合] itens_count, itens_top3_catmat, itens_keywords

[链接] url_pncp, edital_pdf_url, edital_pdf_extracted

[扩展] historical_winners, avg_winning_discount, change_history
```

### 明细表 itens(9 列)

```
pncp_id, numero_item, descricao, quantidade, unidade,
valor_unitario, valor_total, catmat_codigo, catmat_nome
```

### 机构表 orgaos(9 列)

```
cnpj, nome, esfera, uf, municipio,
total_contratacoes_2y, total_valor_2y, last_active_date, tier
```
