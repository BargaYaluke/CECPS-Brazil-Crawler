# 巴西招投标爬取来源设计

> 适用场景:六大维度商机捕捉(数字经济 / 医疗医药 / 高端制造 / 大宗商贸 / 跨境电商 / 文化体育)

---

## 一、PNCP 官方查询 API(主力数据源)

PNCP 提供完整的 RESTful 查询 API(`/api/consulta/v1/`),**公开免认证**,文档齐全。
Swagger 文档:`https://pncp.gov.br/api/consulta/swagger-ui/index.html`

### 1.1 核心 Endpoints

| Endpoint | 用途 | 关键参数 | 优先级 |
|---|---|---|---|
| `/api/consulta/v1/contratacoes/publicacao` | 按**发布日期**查询招标 | `dataInicial`, `dataFinal`, `codigoModalidadeContratacao`, `pagina` |  主力 |
| `/api/consulta/v1/contratacoes/proposta` | 查询**投标期内**(仍可投标)的招标 | `dataFinal`, `codigoModalidadeContratacao` |  主力 |
| `/api/consulta/v1/contratacoes/atualizacao` | 查询某时间段内**有更新**的招标(补登、修改、撤销) | `dataInicial`, `dataFinal` |  增量同步必备 |
| `/api/consulta/v1/atas` | 价格登记表(ARP) | `dataInicial`, `dataFinal` |  推荐 |
| `/api/consulta/v1/contratos/publicacao` | **已签约合同**(看实际中标方、金额) | `dataInicial`, `dataFinal` |  竞品分析必备 |
| `/api/consulta/v1/pca` | **年度采购计划**(提前 6–12 个月预知项目) | `anoPca`, `codigoClassificacaoSuperior` |  商机前置 |
| `/api/pncp/v1/orgaos/{cnpj}/compras/{ano}/{seq}/itens` | 单个招标的**采购明细**(单价、规格、CATMAT 码) | path params |  维度分类的地基 |
| `/api/pncp/v1/orgaos/{cnpj}/compras/{ano}/{seq}/arquivos` | 招标公告**附件下载**(Edital PDF) | path params |  深度分析用 |

### 1.2 codigoModalidadeContratacao(采购方式代码)

需循环遍历,常见值:

| 代码 | 含义 | 说明 |
|---|---|---|
| 1 | Leilão | 拍卖 |
| 4 | Concorrência | 公开招标(大型项目) |
| 5 | Pregão Presencial | 现场竞价 |
| 6 | Pregão Eletrônico | 电子竞价(最常见) |
| 8 | Dispensa | 免招标采购 |
| 9 | Inexigibilidade | 不可招标(独家来源) |
| 12 | Credenciamento | 资质认证 |

### 1.3 强烈建议新增的两个 endpoint

- **PCA(Plano de Contratações Anual)年度采购计划**
  各机构每年初发布次年采购计划,可**提前 6–12 个月**锁定商机。
  适合做季度商机预测、销售管线前置。

- **Contratos(已签合同)**
  反查"谁拿过类似项目",对**竞品分析**和**投标策略**至关重要。
  可统计:历史中标方、平均折扣率、续约规律。

## 二、互补的州/市级专项门户

PNCP 是全国统一平台,但**很多大州/市有独立平台**,数据更早、字段更全,尤其在大额项目上。

| 平台 | 域名 | 覆盖范围 | 备注 |
|---|---|---|---|
| **ComprasNet** | `compras.gov.br` | 联邦级 | 旧系统但联邦级最完整,有 API |
| **BEC** | `bec.sp.gov.br` | 圣保罗州 | 数字经济/IT 项目大户 |
| **LICITANET** | `licitanet.com.br` | 跨州电子竞价 | 不少市政府只在这上面发 |
| **BLL Compras** | `bllcompras.com` | 跨州 | 巴拉那、南部各州 |
| **BNC** | `bnccompras.com` | 跨州 | 多个州市使用 |
| **ComprasBR (TCU)** | `tcu.gov.br` | 审计署口径 | 合规交叉验证用 |
| **Portal da Transparência** | `portaltransparencia.gov.br` | 财政透明度 | 反查机构真实支付能力 |

### 优先级建议

- **第一阶段**:PNCP 全量(覆盖度最高,法律强制要求所有机构发布到此)
- **第二阶段**:加 ComprasNet(联邦级历史数据更全)
- **第三阶段**:按重点州补 BEC、LICITANET(看你的客户主要在哪些州)

## 三、辅助富化数据源(非招标数据本身)

爬到招标数据后,用这些源做"特征增强":

| 数据源 | URL/接口 | 用途 |
|---|---|---|
| **Receita Federal CNPJ API** | `receitaws.com.br/v1/cnpj/{cnpj}` 或 `brasilapi.com.br` | 用机构 CNPJ 反查规模、活跃度、地址、注册资本 |
| **IBGE API** | `servicodados.ibge.gov.br/api/v1/` | 州/市代码 → 区域、人口、GDP,做市场画像 |
| **Banco Central 汇率** | `bcb.gov.br/api/servico/sitebcb/...` | BRL→CNY/USD 实时汇率,补全金额维度 |
| **CATMAT/CATSER 目录** | PNCP API 提供 | 采购品类标准编码,维度分类基础 |
